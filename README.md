Bank Loan Analysis Dashboard (Power BI)

An interactive Power BI dashboard that analyzes 38.6K bank loan applications from 2021. It tracks lending KPIs, separates good loans from bad loans, and shows application trends by month, state, loan term, purpose, employment length, and home ownership.


Tools
Power BI Desktop
Dashboard Pages

Page 1: Summary

Headline KPI cards with month-to-date (MTD) and month-over-month (MoM) change
Good loan vs bad loan comparison
Loan status table (Fully Paid vs Charged Off)

Page 2: Overview

Total loan applications by month
Total loan applications by state (map)
Applications by loan term (36 vs 60 months)
Applications by employment length, purpose, and home ownership

Page 3: Details

Loan-level table with purpose, home ownership, grade, sub grade, issue date, funded amount, interest rate, installment, and amount received

All pages include slicers for purpose, grade, and state.

Key Findings
Good loans made up 86.18% of applications: about 33K applications, $370M funded, and $436M received.
Bad loans were about 5K applications: $66M funded, but only $37M received.
Debt consolidation was the most common loan purpose, with 18.2K applications.
About 73% of applications were for 36-month loans.
Loan applications rose steadily from January to December.
